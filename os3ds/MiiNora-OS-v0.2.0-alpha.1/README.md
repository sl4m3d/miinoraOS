# MiiNora OS v0.2.0-alpha.1

The validated CI package is published as a GitHub Release asset: [MiiNora-OS-Package.tar.gz](https://github.com/sl4m3d/miinoraOS/releases/download/v0.2.0-alpha.1/MiiNora-OS-Package.tar.gz).

SHA-256: `fe4885b5db6c4c5ee3d70818e546e2e58c864d02bebc167db5f59eb554a69af9`

The native CIA downloads the package to `SD:/os3ds/MiiNora-OS-v0.2.0-alpha.1/`. It does not format or create an ext4 partition. Use the included `tools/install-on-linux-host.sh` from a Linux host with prepared FAT32 and ext4 partitions.

The folder stores this small manifest and release pointer; the large package remains a Release asset rather than a Git blob.
